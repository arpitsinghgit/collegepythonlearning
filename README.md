# College Python Learning

A small, responsive landing page for a Python learning path. It is built with plain HTML and CSS and Vite, with no runtime dependencies.

## Run locally

```sh
npm install
npm run dev
```

Create a production build with `npm run build` (output goes to `dist/`).

## Vercel

A production deployment is available at [collegepythonlearning.vercel.app](https://collegepythonlearning.vercel.app). The Vercel build settings are recorded in `vercel.json` (build with `npm run build`, serve `dist/`). Production has been built from this repository's GitHub source. Automatic deployments on future pushes still require connecting the repository through Vercel's GitHub integration.
